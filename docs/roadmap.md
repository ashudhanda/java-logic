# Java Logic — Roadmap 🗺️

Logic building ka step-by-step plan. Har level complete karne ke baad hi agla level start karo.

## Level 1 — Basics
- Input/output, variables, operators
- if-else conditions with dry runs
- Simple math problems (even/odd, max of 3, swap)

## Level 2 — Loops
- for, while, do-while ka flow samajhna
- Counting, sum, factorial, reverse number
- Loop dry run table banana (iteration by iteration)

## Level 3 — Patterns
- Star patterns (square, triangle, pyramid)
- Number patterns
- Nested loop ka dry run

## Level 4 — Arrays
- Traversal, min/max, sum/average
- Search (linear), reverse, frequency count

## Level 5 — Strings
- Palindrome, vowel count, reverse
- charAt + loop combos

## Level 6 — Mixed Problems
- MCQ + output prediction + coding mix
- Timed practice sessions

> Tip: Har problem ko pehle paper pe dry run karo, phir code likho.
