# FAQ ❓

## Logic build hi nahi ho rahi, kya karun?
Normal hai. Logic ek **skill** hai, talent nahi — practice se hi aati hai. Level 1 se shuru karo, aur har problem ka **dry run paper pe** karo. 2-3 hafte consistent practice ke baad difference dikhega.

## Ek problem me kitna time lagana chahiye?
- 15-20 min khud try karo
- Phir hint dekho (solution nahi)
- 10 min aur try karo
- Tab bhi na ho to solution dekho — par **agle din wahi problem bina dekhe** solve karo

## Solution dekhna cheating hai?
Nahi — agar dekh ke samajhte ho aur baad me khud se likh sakte ho. Cheating tab hai jab copy-paste karke aage badh jate ho.

## Pattern problems itne important kyu hain?
Nested loops ki practice ke liye best hain — row/column ka relation samajhna hi asli logic building hai.

## Roz kitne problems karun?
Quality > quantity: **3-4 problems roz** with proper dry run > 20 problems raat bhar me.

## Java hi kyu, koi aur language se logic nahi banti?
Logic language-independent hai. Java isliye kyunki syntax strict hai — shortcuts nahi milte, fundamentals clear hote hain.

## Stuck ho jaun to?
1. Problem ko chhote input pe manually solve karo
2. Apne manual steps ko likho — wahi algorithm hai
3. Steps ko code me convert karo
